## Problem

Guarantee capacity (how many bonded solvers, how much float) is set by committee or fixed parameter everywhere today — either overcapitalized and expensive in calm periods or undercapitalized in stress, with no market force pushing it toward the demand equilibrium.

## Mechanism

Bond supply and coverage demand are both auctioned with a linking rebalancing rule: the spread between the bonded-ness price and the coverage price mints or retires solver bonds, so the guarantee market's capacity finds its own equilibrium. Fragility signals flow into both auction sides (thinning solver sets raise coverage prices and retire capacity), making concentration risk self-pricing and recapitalization automatic.

## Mathematical Model

- `X_t` (input, dimensionless): Exogenous fragility shock: negative = solver-set thinning.
- `F_t` (state, dimensionless): EMA fragility signal (fast EMA).
- `F_slow` (state, dimensionless): Slow fragility EMA (v2: the mint gate reads F_t vs its own slow baseline).
- `C_t` (state, dimensionless): Bonded solver concentration.
- `P_b` (state, dimensionless): Bonded-ness clearing price (netted: one stance per bidder).
- `P_c` (state, dimensionless): Coverage clearing price (netted).
- `N_t` (state, dimensionless): Bond count = capacity.
- `S_t` (state, dimensionless): Pool capitalization.
- `sea_t` (state, dimensionless): Seasoning depth: batches of unseasoned capacity outstanding (v2).
- `spread_t` (output, dimensionless): The rebalancing signal (v2: read through the dead-zone).
- `act_t` (output, dimensionless): Mint/retire action (v2: fragility-gated).
- `F_t1` (state, dimensionless): Next-step fast fragility.
- `F_slow1` (state, dimensionless): Next-step slow fragility.
- `C_t1` (state, dimensionless): Next-step concentration.
- `P_b1` (state, dimensionless): Next-step bonded-ness price.
- `P_c1` (state, dimensionless): Next-step coverage price.
- `N_t1` (state, dimensionless): Next-step bond count.
- `S_t1` (state, dimensionless): Next-step pool capitalization.
- `sea_t1` (state, dimensionless): Next-step seasoning depth.

- `F_t1 = clip(F_t + k_frag * shock_load * max(0, -X_t) * (2 / (1 + frag_span)), 0, 3)` — Fast fragility EMA (span tightened: batch-level clears read fresh signals).
- `F_slow1 = clip(F_slow + (F_t1 - F_slow) * (2 / (1 + slow_span)), 0, 3)` — v2 MINT GATE baseline: the slow EMA of fragility — minting requires the fast signal BELOW this.
- `C_t1 = clip(C_t + k_conc * F_t1, 0, 3)` — Thinning raises concentration (unchanged physics).
- `P_b1 = clip(P_b + 0.2 * N_t - 0.1 + k_manip * manip_budget - 0.05 * sea_t, 0, 3)` — v2: netted single-sided shilling only (k_manip halved — simultaneity impossible), and unseasoned capacity prices WORSE (sea_t drag): diluted bonds are the diluter's own risk.
- `P_c1 = clip(P_c + 0.3 * C_t1 + 0.2 * F_t1 - 0.1 * N_t - k_manip * manip_budget, 0, 3)` — Coverage side (netted; the ambush's peak still funds the pool via premium_load).
- `spread_t = P_c1 - P_b1` — The signal (unchanged definition).
- `act_t = k_spread * max(0, abs(spread_t) - dead_zone) * (max(0, min(1, 1 + (spread_t - dead_zone)))) - k_spread * max(0, abs(spread_t) - dead_zone) * (max(0, min(1, 1 - (spread_t + dead_zone))))` — v2 DEAD-ZONE + FRAGILITY GATE: positive only when spread exceeds +dead_zone (mint path) — gated below by fragility; negative only when spread is below -dead_zone (retire path). The arithmetic splits sign handling without comparison operators.
- `act_t = act_t * (max(0, min(1, 1 + (F_slow1 - F_t1))))` — v2 FRAGILITY GATE: the MINT direction scales by how far below its slow baseline the fast signal sits (mint into strength); RETIRE keeps full force (honest pro-cyclical discovery) — the gate is one-sided by design.
- `N_t1 = clip(N_t + a_step * max(-1, min(1, act_t / a_step)), n_min, n_max)` — Bond count follows the gated action, move-capped, bounded (unchanged).
- `sea_t1 = clip(sea_t + max(0, N_t1 - N_t) * 10 - (sea_t / season_batches), 0, 10)` — v2 SEASONING: new mints add unseasoned depth; it decays over season_batches — new capacity must survive the seasoning window for full pricing.
- `S_t1 = clip(S_t + premium_load * P_c1 * N_t - 0.05 * N_t, 0, 3)` — Pool recapitalizes from coverage premiums (unchanged; the ambush funds it).

**Parameters:** k_frag ∈ [0.05, 1.5] (default 0.4), frag_span ∈ [2.0, 50.0] (default 6.0), slow_span ∈ [5.0, 100.0] (default 30.0), k_conc ∈ [0.0, 1.0] (default 0.3), a_step ∈ [0.01, 0.3] (default 0.1), dead_zone ∈ [0.0, 1.0] (default 0.3), k_spread ∈ [0.0, 2.0] (default 0.5), n_min ∈ [0.5, 3.0] (default 1.0), n_max ∈ [1.0, 5.0] (default 3.0), premium_load ∈ [0.0, 1.0] (default 0.3), manip_budget ∈ [0.0, 10.0] (default 1.0), k_manip ∈ [0.0, 1.0] (default 0.1), season_batches ∈ [1.0, 50.0] (default 12.0), shock_load ∈ [0.0, 1.0] (default 0.5)
