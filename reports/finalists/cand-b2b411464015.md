## Executive Summary

## Problem

Oracle failure becomes a halt or an unpriced risk; degraded data keeps being consumed at the same price as honest data

## Mechanism

Oracle failure is a priced service level: a fee ladder makes degraded data expensive to use and funds sender insurance. The r11 correction: the ladder's open-interest index reads a directional-sustained EMA of SIGNED relative moves, not instantaneous volatility, so crafted zero-mean oscillation cannot inflate the index and harvest fee discounts

## Mathematical Model

- `X_t` (input, unit): anchor price level (~1000)
- `dX_t` (input, unit): anchor change that step
- `T_t` (state, unit): EMA of signed relative anchor moves
- `T_t1` (state, unit): next trend index
- `O_t` (state, unit): trend-keyed open-interest index
- `O_t1` (state, unit): next open-interest index
- `F_t` (state, unit): fallback read fee level
- `F_t1` (state, unit): next fee level
- `R_t` (state, unit): fast EMA of the signed level path (fee side)
- `R_t1` (state, unit): next fast trend

- `T_t1 = clip(T_t + kappa*((1000.0 + (dX_t/max(X_t,1.0))*1000.0) - T_t), 200.0, 1800.0)` — index-side EMA (slow)
- `O_t1 = clip(O_t*(1-gamma) + gamma*(oi_floor + 40.0*abs(T_t-1000.0)/10.0 + 12.0*sqrt(abs(dX_t)/max(X_t,1.0))), 350.0, 1600.0)` — index keys to slow trend; kicker shrunk to clip-safe scale
- `F_t1 = clip(F_t*(1-delta) + delta*(600.0 + 140.0*max(0.0, abs(R_t1-1000.0)) + 90.0*max(0.0, 1200.0-O_t1)/100.0), 400.0, 1700.0)` — fees track the FAST EMA first (reprice ahead of harvest) plus the degraded-index term
- `R_t1 = clip(R_t + kappa_f*((1000.0 + (dX_t/max(X_t,1.0))*1000.0) - R_t), 200.0, 1800.0)` — fee-side EMA (fast): fees reprice AHEAD of index drift

**Parameters:** kappa ∈ [0.05, 0.5] (default 0.18), gamma ∈ [0.05, 0.5] (default 0.15), delta ∈ [0.05, 0.6] (default 0.25), oi_floor ∈ [300.0, 800.0] (default 500.0), kappa_f ∈ [0.2, 0.9] (default 0.45)

**Open questions (§13):** should the trend index blend a second slower EMA for regime memory?

**Critical assumptions:** the trend EMA of signed moves is a faithful degradation proxy: sustained data decay shows as drift, wash shows as zero-mean noise
